Privacy Policy

Content Draft Assistant  ·  Last updated: see footer

Content Draft Assistant ("the tool") is a content management utility that helps a creator move their own finished video files into their own TikTok draft inbox. This policy describes exactly what the tool handles.

What the tool accesses

  • TikTok account identity. With the user.info.basic scope, the tool reads the basic identity of the account that explicitly authorizes it, so it can confirm which account it is acting for.
  • OAuth tokens. The tool stores the access and refresh tokens issued when the creator authorizes it, so it can act for that creator without asking again each time.
  • Video files. Only files the creator supplies to the tool.

What the tool does not access

  • It does not scrape TikTok or any other platform.
  • It does not read data belonging to other TikTok users.
  • It does not read the creator's messages, followers, or analytics unless separately authorized.
  • It does not perform automated engagement of any kind.

How data is stored

  • OAuth tokens are stored locally on the operator's own machine, in a local state file.
  • Video files remain local until they are transferred to the creator's own TikTok draft inbox.
  • No TikTok user data is sold, rented, or shared with third parties.

Third parties

The tool transmits data only to TikTok's official API endpoints, and only the data required to place the creator's own video into their own draft inbox. It does not send data to advertisers, brokers, or analytics providers.

Retention and deletion

  • A creator can revoke the tool's access at any time in TikTok's settings, under Security & permissions → Manage app permissions.
  • Deleting the local state file removes the stored tokens.
  • Videos already uploaded to TikTok are managed through the creator's own TikTok account.

Children

The tool is not directed to children and is not intended for use by anyone below the minimum age required to hold a TikTok account.

Changes

If this policy changes, the updated version will be posted on this page with a revised date.
