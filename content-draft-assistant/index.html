Content Draft Assistant

A content management tool for creators.

Content Draft Assistant takes video files that a creator has already produced and uploads them to that creator's own TikTok draft inbox using the official TikTok Content Posting API in Upload mode.

The creator then opens TikTok, reviews the draft, edits it if needed, and publishes it themselves. The assistant never publishes on the creator's behalf.

What it does

  • Transfers the creator's own finished videos into their own draft inbox.
  • Identifies the authorized account via the user.info.basic scope.
  • Requires the creator to review and post manually inside TikTok.

What it does not do

  • It does not publish automatically. Direct Post is not used.
  • It does not scrape TikTok or read other users' data.
  • It does not follow, like, comment, or message — there is no engagement automation.
  • It does not source or republish content from other accounts.
